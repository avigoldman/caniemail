# caniemail

Check HTML and CSS Feature Support for Email Clients from [caniemail.com](https://caniemail.com)

## Project Moved

Avi was gracious and allowed access to the repository and npm package and we were able to put together v1.0.0, a major leap forward in the utility of this package. Sometimes life happens, and Avi has been on sabbatical of sorts and we need some additional access to the repository to enable automatic releases, etc. To get our CI automations working, we've had to move the repository to https://github.com/shellscape/caniemail. We hope this is temporary and when Avi is back in action, we'll be happy to move the codebase back to this repository. Please look to that location for pull requests, issues, and support.

I (@shellscape) would like to reiterate again how grateful I am that Avi allowed me to use the package to deliver some great functionality to the community.
